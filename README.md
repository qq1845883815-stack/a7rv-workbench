# A7R V 工坊 / A7RV Workbench

macOS Apple Silicon 的 Sony ILCE-7RM5 研究工具，当前为 **0.1.0 研究测试版**。基于 [a7r5-rea](https://github.com/Liwenru88/a7r5-rea) 提交 `290c79e65fb52b5b64ac64a1c9a835a63d7d821f`。

**仅适配指定官方 4.00 与两种已知一号分区原像。不是索尼官方软件，也不是适用于所有 4.00 相机的成熟安装器。** 未知摘要会停止；不支持强制安装。分区写入或卡刷失败可能导致相机无法启动；单个分区备份不等于全机备份，目前没有已验证的故障救援流程。

应用仅作临时签名，未经 Developer ID 签名或 Apple 公证。macOS 可能要求在隐私与安全性设置中批准打开。仅使用自己核对过来源和摘要的安装包。

## 功能

- 显式检查 USB 海量存储连接，采集一号分区并核验完整副本。
- 仅对已识别完整原像生成固定的 258 扇区信任修改事务，写入后完整回读核验。
- 用户自行提供指定官方 4.00 `BODYDATA.DAT` 后离线封包：FL2/FL3、六款模拟滤镜、关闭 NTSC 提示、电子快门声音。
- 选择升级卡、排除已有同名更新文件，复制后完整核验并安全推出。机内更新须由用户手动操作。
- 保留任务记录；未确认的设备事务阻止后续设备操作。启动不会自动访问相机。

**SSH 暂未提供。** 不提供清除失败标记重试、自动刷机、自动回滚或跨版本适配。

## 数据与公开内容

本仓库和发行包不包含照片、完整相机分区镜像、官方或修改后的完整 DAT、使用者的任务记录、批准记录或账户凭据。应用数据保存在 `~/Library/Application Support/local.a7rv.workbench`，与旧 REA 应用分开。

发行包含两个布局的固定 258 扇区前像／后像片段、机内程序模板及源码。片段来自启动镜像及其校验区域，用于严格匹配和限定写入；不是完整个人相机备份。也包含上游**公开研究签名私钥**，它是用于研究封包的公共身份，不是索尼签名私钥、用户 SSH 私钥或账户凭据。不要把它用于保护任何私人数据。

## 源码、构建与测试

完整源码目录随 `A7RV-Workbench-0.1.0-source.zip` 提供。解压后查看 `BUILD.md`。源码包包含 Swift 界面、Python 后台、Web 界面、机内 C 源码、固定模板与扇区方案、引擎源码和第三方通知。此版本以源码归档发布，仓库根目录保存说明与校验值。

构建需要 macOS/Xcode 命令行工具以及发行版应用中的已组装运行环境。源码构建会重新编译 Swift 并重新生成资源封条；Python、第三方扩展和机内模板复用封存产物，并非从空白系统完整重建所有依赖。
